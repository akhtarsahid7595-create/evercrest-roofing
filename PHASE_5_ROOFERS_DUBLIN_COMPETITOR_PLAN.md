## Opportunity diagnosis

The competitor is visible, but it is not an unbeatable authority. Its strongest advantage is breadth of service and location language, not overwhelming organic strength. The main opportunity is to build a smaller but more trustworthy topical system around Evercrest's real services:

1. Make each approved service page more complete and useful than the competitor's equivalent page.
2. Build supporting problem/guide content only where it directly helps a customer and a service page.
3. Use genuine project evidence, reviews, and local trust instead of unsupported claims.
4. Improve internal linking so Google and customers can understand the relationship between services and guides.
5. Earn relevant local/trade links gradually.

# Phase 1 — Validation and page architecture

### Goal

Turn the competitor data into a safe, client-specific page map before publishing anything.

### Work

- Confirm the client's complete current offer and service exclusions.
- Confirm the exact Evercrest URLs for the six completed service pages.
- Export the full Semrush Keyword Gap and Organic Pages reports, not screenshots only.
- Group the 37 missing keywords by intent and remove irrelevant, branded, unsupported, or duplicate terms.
- Map each valid keyword group to an existing Evercrest page, a possible new service page, or a supporting guide.
- Check Google Search Console for existing impressions and queries before deciding that a keyword is truly missing.
- Check indexation, titles, headings, canonicals, sitemap coverage, internal links, and mobile presentation.
- Establish a baseline for impressions, clicks, average position, calls, quote forms, and page engagement.

### Output

- Approved service matrix
- Keyword-to-URL map
- Competitor-versus-Evercrest page gap table
- Internal-linking map
- Baseline measurement sheet

### Gate before Phase 2

No new page is written until the client approves the service matrix and the keyword groups are checked for cannibalisation.

# Phase 2 — One controlled new-page test

### Goal

Create and measure one high-confidence page rather than releasing a large batch.

### First candidate

Prioritise the strongest genuine gap among:

- A new page for an approved service not yet represented on Evercrest; or
- A supporting guide for an urgent customer problem such as what to do when a roof is leaking.

The exact choice depends on the client's offer and the current site URLs. Do not select fascia, soffit, downpipe, slate, tile-painting, or replacement pages simply because the competitor has them.

### Page standard

- One clear search intent.
- Original, verified Evercrest information.
- Clear service area and contact path.
- Practical customer guidance.
- Three to five genuine FAQs where useful.
- Links to two or three relevant existing service pages.
- One or more approved images or project examples if available.
- Accurate title, meta description, headings, image alt text, and appropriate schema.
- No copied competitor wording, fake claims, fake reviews, or artificial keyword repetition.

### Measurement window

Allow Google to crawl and evaluate the page. Review early indexing signals, then compare performance after approximately 4–8 weeks before publishing the next batch.

# Phase 3 — Approved service cluster expansion

### Goal

Expand gradually around the service with the clearest evidence from Phase 2.

### Work sequence

1. Improve or create one related commercial page only if the client offers it.
2. Add one supporting guide addressing a real customer question.
3. Add contextual internal links between the service page, guide, and relevant completed pages.
4. Add approved project evidence or testimonials.
5. Request genuine reviews and pursue a small number of relevant local/trade citations.
6. Recheck Search Console, rankings, conversions, and cannibalisation.

### Possible clusters, subject to approval

- Emergency roof repair → roof leak guide → roof repairs
- Chimney repairs → chimney flashing/leak guide → roof repairs
- Gutter repairs/cleaning → blocked-gutter guide → fascia or wall-damage guidance only if the service is offered
- Flat roofing → flat-roof problem guide → repair-versus-replacement guidance only if accurate and within the offer
- VELUX → VELUX repair information only after confirming the exact service scope

# Phase 4 — Authority and local trust

This phase follows evidence from the first three phases.

- Compare the competitor's referring domains with Evercrest's.
- Pursue relevant Irish trade, local, supplier, and community opportunities.
- Improve Google Business Profile completeness and consistency.
- Collect genuine reviews through normal customer processes.
- Add real project pages or case-study sections as evidence becomes available.
- Avoid mass directory submissions, paid spam links, fabricated locations, and automated review activity.

# Phase 5 — Review and next competitor cycle

- Compare rankings and conversions against the initial baseline.
- Identify which page types generated impressions, enquiries, and qualified calls.
- Keep, improve, merge, or retire pages based on evidence.
- Only then begin the next competitor DNA cycle.
